# Support

Use the [issue forms](https://github.com/bolens/omarchy-multi-monitor-workspaces/issues/new/choose)
for reproducible bugs and feature requests. Include the Omarchy version, plugin
version, connected output names, relevant settings, and minimal reproduction
steps. Remove usernames, private paths, and unrelated logs before posting.

Use [private vulnerability reporting](https://github.com/bolens/omarchy-multi-monitor-workspaces/security/advisories/new)
for security concerns. Response and resolution times are not guaranteed.
